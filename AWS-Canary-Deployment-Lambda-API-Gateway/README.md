# Case Study: Canary Deployment Using Lambda and API Gateway

## Objective
Test a new application version with a sample of traffic before directing all traffic to it.

## Overview
This project documents a canary deployment using AWS Lambda and Amazon API Gateway. It covers publishing Lambda versions, creating aliases, configuring API Gateway stage variables, directing a percentage of traffic to a new version, testing responses, and promoting the canary deployment.

## Key Tasks
- Create a Lambda function and publish versions.
- Configure production and development aliases.
- Create an API Gateway REST API and integrate it with Lambda.
- Configure stage variables and canary traffic distribution.
- Test responses from both versions.
- Promote the canary deployment after validation.

## Documentation
This folder contains the case study report and practical screenshots showing the deployment and testing steps.

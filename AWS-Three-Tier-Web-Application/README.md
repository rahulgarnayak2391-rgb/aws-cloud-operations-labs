# AWS Three-Tier Web Application

## Project Overview
This project documents hands-on AWS practice involving VPC, EC2, security groups, RDS MySQL, S3 image integration, AMI creation, and load balancer security configuration.

## Tasks Documented
1. Created a VPC and security groups.
2. Configured an EC2 instance.
3. Created an RDS MySQL database and tested connectivity.
4. Integrated website images with Amazon S3.
5. Created an AMI and prepared security groups for an Application Load Balancer.
